# ExperimentalHS

A native Windows desktop launcher for
[Hypseus Singe](https://github.com/DirtBagXon/hypseus-singe) by
**DirtBagXon**, built with Kotlin and Compose Multiplatform Desktop. See
`windows/`.

Nothing here is released, supported, or intended for general use. There
are no builds to download and none are planned.
