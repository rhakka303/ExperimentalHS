# ExperimentalHS

Experimental port of [Hypdroid](https://github.com/rhakka303/Hypdroid) and
[Hypseus Singe](https://github.com/DirtBagXon/hypseus-singe). Concept
experimental.

Nothing here is released, supported, or intended for general use. There
are no builds to download and none are planned.
